01

Bound the whole agent tree

Each child makes model requests and can request descendants. Use independent depth, concurrency and estimated spend limits instead of assuming a short prompt bounds the work.

02

Understand depth versus concurrency

Depth 1 removes child spawning from the bottom layer. Depth 2 permits a coordinator and grandchild auditor. Concurrency caps simultaneously admitted Agent children and returns native refusals when full.

03

Handle native budget results

A tiny maxBudgetUsd produces error_max_budget_usd. Retain the native result before handling the SDK exception. The spend estimate includes child requests and can be crossed by an in-flight request.

04

Preserve and extend the environment

Spread process.env in TypeScript options.env to preserve PATH and private model credentials. Set explicit string-valued depth and concurrency caps for each run.

05

Control Opus 5 delegation

Compare a custom orchestration instruction with the claude_code preset using an explicit delegation request. Prompts steer choices; configured runtime limits enforce the admitted work.

06

Move orchestration into Workflow

Use the actual Workflow tool and a reviewed JavaScript script to audit three files. Compare pipeline fan-out with serial awaits, inspect native hooks and reports, and understand how script variables keep intermediate results out of the main conversation.
